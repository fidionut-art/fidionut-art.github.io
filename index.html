smc-bot

A private algorithmic trading application built on the cTrader Open API.

What it does

smc-bot is a self-hosted program that implements a Smart Money Concepts strategy on index CFDs and FX. It evaluates a fixed rule set on closed candles and places orders with a stop loss attached to every position.

It runs for a single trading account owned by its author. It is not a signal service, it is not sold or licensed, and it does not manage funds for anyone else.

How the Open API is used

  • Reading account state: balance, equity, open positions and pending orders.
  • Reading historical and live price data for the traded symbols.
  • Placing, modifying and cancelling orders on the author's own account.

Access tokens are stored locally and never shared. The application has no public interface, no user accounts, and collects no data from anyone.
